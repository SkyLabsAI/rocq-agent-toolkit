`rocq-ed`: A Command-Line Editor for Rocq
=========================================

This package provides a binary called `rocq-ed`, which can be used to maintain
an interactive editor session on a Rocq source file. It can be used to move to
any point in the file, inspect proof goals, and even insert new contents. This
provides an alternative to the typical top-level or LSP severs. It can be used
by AI agents to efficiently query and modify Rocq source files.

Run `rocq-ed --help` for more details.
